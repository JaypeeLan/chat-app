# Agent / automation notes

## Git commits

- Do not add `Co-authored-by:`, `cursoragent@cursor.com`, or any IDE/tool attribution to commits.
- Prefer a single-line commit: `git commit -m 'subject: short description'` (avoid chained `-m` blocks that invite extra trailers).

To stop Cursor from appending Co-authored-by on commits made from the product: **Cursor Settings → Agent → Attribution → disable commit attribution** (wording may vary by version).
